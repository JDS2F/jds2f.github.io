Privacy Policy

Last updated: October 3, 2026

Homelab Backup is a personal backup tool used only by its owner, Jackson Shaw. It is not a public service.

Data accessed

With the owner's permission, the app reads and writes files in the owner's own Google Drive to store and manage encrypted backups. It accesses no other Google user data.

Data use and sharing

Backup files are encrypted on the owner's servers before upload. No data is collected, sold, shared with third parties, or used for advertising or analytics. Google user data is used only to provide the backup function.

Storage and retention

Backups live only in the owner's Google Drive and are automatically pruned after a fixed number of weekly snapshots. The sign-in token is stored only on the owner's own computers.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
